# Mesto

Интерактивная страница для просмотра и добавления фотографий мест.

## Ссылка на проект

[Открыть проект](https://gostereman.github.io/mesto-production/)

## Команды

Установка зависимостей:

```bash
npm install
```

Запуск локального сервера разработки:

```bash
npm run dev
```

Сборка проекта:

```bash
npm run build
```

Публикация на GitHub Pages:

```bash
npm run deploy
```

## Технологии

- HTML5, CSS3, JavaScript (ES6+)
- Vite
- REST API
